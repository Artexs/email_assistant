# F112 stage 04: front matter, docs:stale, UiText (notes for stage 05 and later)

- `apps/docs/src/front-matter.ts`: `USER_SECTIONS`, `POLISH_SET` (`["index"]`; stage 10 adds the P6 pages), `frontMatterSchema` (`capabilities`, `source`, `sourceHash`), `frontMatterProblem`, `frontMatterLoader`. A schema cannot see the page id, so the rule "a user page names a capability" runs in `frontMatterLoader`, which wraps `inPlaceLoader()` in `content.config.ts` and checks every entry after the load. Error: `front_matter capabilities <id>`.
- `capabilities` values are the file names in `docs/capabilities/` without `.md`. `README.md` there is the index and does not count. A non-user page may omit `capabilities`, but one it names must exist.
- `apps/docs/scripts/stale.ts` (`bun run docs:stale [--strict] [--stamp <pl file>]`): prints through `createCliOutput("docs-stale")` (relative import from `apps/server/src/platform/cli`; no lint border blocks it). `EA_DOCS_CONTENT_DIR` points it at a fixture folder (tests only). Findings that fail: no `source` or `sourceHash`, source page missing, id of `POLISH_SET` without `pl/<id>`, and with `--strict` a stale page whose source is `index` or starts with `start`. A plain stale page prints `stale pl/<id> (source <id>)` and exits 0.
- `--stamp` writes `sourceHash: "<16 hex>"` with quotes: 16 digits (or `1e…`) would read as a number in YAML and fail the schema. It keeps line ends and every other line.
- `bodyHash` removes only whole lines that hold a `<Shot … />` tag (the tag may span lines). Removing the line does not remove the blank lines around it: a Shot between two blank lines leaves two blank lines. Stage 11: if that stales a page, add the Shot line and restamp, or change `bodyHash` with a test.
- Any edit of an English page that has a Polish page (today `index.mdx`) makes `docs:stale` print `stale`. Restamp: `bun run docs:stale --stamp apps/docs/src/content/docs/pl/index.mdx` after you check the Polish text. The unit test of the real repository asserts exit 0 and a `stale: <n>` line, not `stale: 0`.
- `<UiText k="…" />` (`src/components/UiText.astro`, lookup `src/ui-text.ts`): `Astro.currentLocale` `pl` reads `pl`, every other value (`root`, `en`, undefined) reads `en`. It throws `ui_text_unknown <k>` and `ui_text_has_vars <k>` (a `{name}` placeholder in either language). In MDX import it with a relative path: `../../components/UiText.astro` from `src/content/docs/<page>.mdx`, one more `../` under `pl/` or a folder. `apps/web/package.json` has `exports` for `./i18n/en` and `./i18n/pl` only: a deep import of another file of `@ea/web` now fails.
- `eslint.config.js`: the astro plugin config now covers `apps/docs/**/*.astro`. Without it ESLint crashed with `Could not find "client-side-ts" in plugin "astro"` on the first `.astro` file outside `apps/web`.
