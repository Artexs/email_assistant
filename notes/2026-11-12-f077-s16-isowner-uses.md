# F077 s16: `isOwner` uses, decided per use

Rule: `isOwner = role === "owner" && canWrite(me)` is the edit right. A text that names the owner role reads `role` alone (`isOwnerRole`), so a paused owner does not read "Only the owner can change this."

- `MailboxesPage`: connect button, `?connect=1` effect, `ConnectDialog`, `MailboxCard` controls → edit right. No role text.
- `OnboardingPage`: connect link, keep-shadow and open-settings buttons → edit right. `ob_mailbox_assistant` and `ob_mode_open`/`ob_mode_assistant` text choice → role (`isOwnerRole`).
- `RulesPage`: `AddRuleForm`, delete buttons in `RuleList` → edit right. `set_owner_only` text → shown only when role is not owner. A paused owner sees no form and no text (the banner explains).
- `SettingsPage`: `ModeCard`, `CategoriesCard`, `SyncFoldersCard`, `SignatureCard`, `TimezoneCard` → edit right. Both `set_owner_only` lines → role.
- Member writes (every role): `ActionButtons`, `DigestTimesCard`, `TelegramLink` read `useMe()` and turn off on `!canWrite(me)`.
- Not changed: `AccountCard` (own password and sessions, better-auth route, not an organization write); `ActivityPage` (no write of its own).
- e2e: the DB `email_assistant_f077s16_e2e` was made for this job (`bun run db:worktree f077s16_e2e`); its URLs are in the worktree `.env` as `E2E_*`.
