## Stage 6 — `createApp({ checkDb, web })`: the middleware chain of W8, `requireSession`, the auth mount with the W1 request, static serving (D6), errors (D9); the route matrix and the HTTP log test [risky]

  - Goal: the HTTP platform of D5, D6 and D9 as one testable `createApp({ checkDb, web })`, with nothing module-specific inside (the module routers mount through `web.routers`, stage 8), proven by a request matrix and by a log test over HTTP.

  - Decisions:
    - Order inside `createApp` (W8): (1) `app.use("*", accessLog)`: after `next()`, `log.debug` of the method, `c.req.routePath`, the status and the milliseconds (never the raw path or the query: a path can hold a token); (2) `secureHeaders({ contentSecurityPolicy: { frameAncestors: ["'none'"] }, xFrameOptions: "DENY", referrerPolicy: "same-origin", strictTransportSecurity: web !== null && web.baseUrl.protocol === "https:" ?       Then with `web`: (4) `app.use("/api/*", bodyLimit({ maxSize: 64 * 1024, onError: (c) => c.json({ error: "too_large" }, 413) }))` (D9 shape; Hono's default is `text/plain`); (5) `app.use("/api/*", originCheck)`: `!originAllowed(c.req.raw, web.trustedOrigins)` → `c.json({ error: "bad_origin" }, 403)`; (6) `app.on(["GET", "POST"], "/api/auth/*", …)`: `path = new URL(c.req.url).pathname.slice("/api/auth".length)`; `!isAllowedAuthPath(c.req.method, path)` (stage 3) → `c.json({ error: "not_found" }, 404)`; else `web.auth.handler(authRequest(c.req.raw, clientAddress(web.connInfo(c), c.req.header("x-forwarded-for"), web.trustedProxies)))`; (7) `const api = new Hono<ApiEnv>()`: `api.use("*", requireSession)` (401 `{ error: "unauthorized" }` when `readSession` gives null), then the stage 8 `requireTenant`, then `web.routers?.(api)`, then `api.all("*", (c) => c.json({ error: "not_found" }, 404))`; `app.route("/api", api)`; (8) pages: `app.use("*", pageGate)`: methods other than `GET`/`HEAD` → `c.text("not found", 404)`; a public path (`PUBLIC_PAGE_PATHS`) → `next()`; else `readSession(c)`; null → `c.redirect("/login?next=" + encodeURIComponent(safeNext(path)), 302)` (built with a template literal in code); `path === "/"` → `c.redirect("/onboarding", 302)` (W5; stage 8 and S5b refine with `onboarding`); (9) `serveStatic({ root: web.dist, onFound: (filePath, c) => c.header("Cache-Control", filePath.includes("/_astro/") ?     - `app.onError` (W8): `error instanceof HTTPException` → `error.res ?? c.json({ error: error.message || "error" }, error.status)` (`ValidationError` from `parseBody` carries its JSON `res`); a `ZodError` or any other error → `log.error` of the method, `c.req.routePath` and `describeError(error)`, then `c.json({ error: "internal" }, 500)`.
