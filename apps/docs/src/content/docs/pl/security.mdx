Ta strona mówi, co asystent robi z Twoją pocztą i danymi.
Każde twierdzenie ma link do pliku w repozytorium, który je potwierdza, oraz warunek, gdy twierdzenie zależy od instalacji.
Twierdzenia, którego żaden plik nie potwierdza, na tej stronie nie ma. Sekcja „Czego ten produkt nie obiecuje” wymienia to, czego nie wolno Ci zakładać.

## Krótka lista

- [Asystent nigdy sam nie wysyła wiadomości z Twojej skrzynki](#claim-never-sends-alone): właściciel zatwierdza każdy szkic.
- [Co dostaje dostawca AI](#claim-ai-provider-receives): treść, temat i nadawcę wiadomości oraz do trzech wcześniejszych wiadomości z jej wątku jako kontekst. Asystent nie klasyfikuje wiadomości starszej niż 7 dni, chyba że operator jednorazowo załaduje starszą pocztę albo działa opcjonalna kontrola historii; wiadomości kontekstowe mogą być starsze.
- [Co dostaje dostawca AI przy szkicu odpowiedzi](#claim-ai-provider-reply-drafts): wiadomość, na którą odpowiada szkic, teksty profilu skrzynki i linię polecenia. Opcjonalna funkcja, domyślnie wyłączona. [Co dostaje przy podpowiedzi stylu](#claim-ai-provider-style-suggestion): do 100 własnych wysłanych wiadomości z ostatnich 14 dni, po odcięciu cytatów, po kliknięciu właściciela.
- [Co dostaje Telegram](#claim-telegram): tylko pozycje, które wymienia tekst zgody.
- [Kopie zapasowe](#claim-backups): szyfrowane, zanim opuszczą serwer.
- [Eksport i usunięcie](#claim-export-and-delete): operator eksportuje, usuwa i kasuje dane na prośbę.
- [Cofnij](#claim-undo): automatyczne przeniesienie możesz cofnąć przez 7 dni.

## Usługi, które dostają dane

Tabela wymienia zewnętrzne usługi, które mogą dostać dane od asystenta. Kolumna „Używana, gdy” podaje warunek dla każdej z nich: jedne działają zawsze, inne tylko wtedy, gdy operator je skonfiguruje.
Gdy operator konfiguruje dostawcę SMTP, asystent wysyła przez niego własne wiadomości logowania (linki do resetu hasła i zaproszenia). To nie są wiadomości z Twojej skrzynki.
Instalacja może używać innego dostawcy AI; dokumenty prawne instalacji wymieniają usługi, których ona używa.
„Jeszcze niepotwierdzone” znaczy, że projekt nie zapisał jeszcze i nie sprawdził tego faktu.

## Hosting tej strony

Ta strona działa na GitHub Pages. GitHub zapisuje adres IP każdego odwiedzającego.
Strona nie ustawia plików cookie, nie ma analityki i nie przechowuje danych użytkowników.
GitHub hostuje wyłącznie tę publiczną stronę. Nie dostaje od asystenta żadnych danych z poczty.

## Czego ten produkt nie obiecuje

- Brak certyfikatu i audytu. Projekt nie ma raportu SOC 2 ani ISO 27001.
- Brak przeglądu prawnego. Prawnik nie sprawdził tekstów prawnych produktu.
- Brak przetwarzania AI wyłącznie w UE jako ustawienia domyślnego. Domyślna konfiguracja wysyła treść wiadomości do dostawcy AI bez ustawienia „tylko UE”.
- Brak szyfrowania end-to-end powiadomień Telegrama. Telegram może przeczytać to, co wysyła do niego asystent.
- Szkice mogą być błędne. Zatwierdzasz każdy szkic, zanim asystent go wyśle.
- Fakty, które pochodzą tylko od dostawcy AI:
  - Dostawca podaje, że nie używa danych ze swojego płatnego API do trenowania modeli ([jego strona o kontroli danych](https://platform.openai.com/docs/guides/your-data), stan na 2026-11-17). Ten projekt nie sprawdził umowy.
  - Dostawca podaje, że oferuje region UE jako ustawienie projektu ([jego strona o lokalizacji danych](https://platform.openai.com/docs/guides/data-residency), stan na 2026-11-17). Ten projekt nie sprawdził ustawienia regionu w projekcie, którego używa instalacja.
- Fakty, które pochodzą tylko od opcjonalnego dostawcy AI, a nie z konfiguracji domyślnej:
  - Gdy instalacja używa DeepSeek, dostawca podaje, że zbiera, przetwarza i przechowuje dane osobowe w Chińskiej Republice Ludowej ([jego polityka prywatności](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html), stan na 2026-11-26).
  - Ten projekt nie sprawdził, czy DeepSeek używa danych z API lub je przechowuje.
