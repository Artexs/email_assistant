This page says what the assistant does with your mail and your data.
Each claim has a link to the file in the repository that proves it, and a condition when the claim depends on the setup.
A claim that no file proves is not on this page. The section "What this product does not promise" lists what you must not assume.

## The short list

- [The assistant never sends a mail from your mailbox alone](#claim-never-sends-alone): an owner approves each draft.
- [What the AI provider receives](#claim-ai-provider-receives): the text, subject and sender of a mail, and up to three earlier mails of its thread as context. The assistant does not classify a mail older than 7 days, unless the operator loads old mail once or the optional history check runs; the context mails can be older.
- [What the AI provider receives for a reply draft](#claim-ai-provider-reply-drafts): the mail that the draft answers, the profile texts of the mailbox and the instruction line. An optional feature, off by default. [What it receives for a style suggestion](#claim-ai-provider-style-suggestion): up to 100 own sent mails of the last 14 days, cut, after an owner tap.
- [What Telegram receives](#claim-telegram): only the items that the consent text names.
- [Backups](#claim-backups): encrypted before they leave the server.
- [Export and delete](#claim-export-and-delete): the operator exports, deletes and erases on request.
- [Undo](#claim-undo): you can reverse an automatic move for 7 days.

## Services that get data

The table lists the outside services that can get data from the assistant. The column "Used when" gives the condition for each one: some are in use always, others only when the operator sets them up.
When the operator sets up an SMTP provider, the assistant sends its own sign-in mails (reset and invite links) through it. These are not mails from your mailbox.
An install can use another AI provider; the legal papers of an install name the services that it uses.
"Not confirmed yet" means that the project has not yet written down and checked this fact.

## Hosts of this site

This site runs on GitHub Pages. GitHub logs the IP address of each visitor.
The site sets no cookies, has no analytics and holds no user data.
GitHub hosts this public site only. It gets no mail data from the assistant.

## What this product does not promise

- No certification or audit. The project holds no SOC 2 or ISO 27001 report.
- No legal review. A lawyer has not checked the legal texts of the product.
- No EU-only AI processing by default. The default setup sends mail text to the AI provider with no EU-only setting.
- No end-to-end encryption of Telegram notices. Telegram can read what the assistant sends to it.
- Drafts can be wrong. You approve each draft before the assistant sends it.
- Facts that come only from the AI provider:
  - The provider states that it does not use data of its paid API to train its models ([its data-controls page](https://platform.openai.com/docs/guides/your-data), read 2026-11-17). This project has not checked the contract.
  - The provider states that it offers an EU region as a project setting ([its data-residency page](https://platform.openai.com/docs/guides/data-residency), read 2026-11-17). This project has not checked the region setting of the project that an install uses.
- Facts that come only from an optional AI provider, not from the default setup:
  - When an install uses DeepSeek, the provider states that it collects, processes and stores personal data in the People's Republic of China ([its privacy policy](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html), read 2026-11-26).
  - This project has not checked whether DeepSeek uses or keeps API data.
