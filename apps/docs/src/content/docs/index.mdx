This site holds the guides and the reference for the Email Assistant. It also holds the operator docs and the changelog.

Start with the [tutorial](start/). It takes you from your invite link to your first digest.
The [FAQ](faq/) answers the questions of the first week.

Use the how-to guides for one task, the reference for facts and the explanations for reasons. The sidebar lists them.
The home page, the tutorial, the how-to guides, the FAQ and "How a mail is sorted" also exist in Polish. The reference and the operator docs are in English only.
