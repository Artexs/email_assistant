# F129 questions (planner defaults, owner to confirm)

None blocks the build. Each item: the default the plan takes, the rejected option, and how to undo it.

1. **[important: user-visible] Exit codes change for operators and agents.** Default: bad arguments exit 2 in every tool; a refusal after valid arguments exits 1 (`mailbox:settings auto` without go, `mailbox:check` refused host, `delegates` refused address, `release:prepare` refused version, `testmail:*` "nothing sent yet" were 2); a stopped `eval --sim` or drafter eval exits 4 (was 2). Rejected: keep the old codes per tool (no single table for agents). Undo: a follow-up that maps one tool back. Plan D5.
2. **[important: user-visible] Two danger tools need `--confirm`.** Default: `org:break-glass --confirm <organization name>` and `web:two-factor-reset --confirm <user id>`; every data-changing danger tool gets `--dry-run`. Runbooks in `deploy/README.md` change in stage 05. Rejected: no new guard (the risk class alone). Undo: drop the check in the two args files. Plan D8.
3. **[important: scope] `gemini:test` is removed.** Default: remove; `bun run llm:check --provider gemini` does the same. The ticket assumed F138 would remove it; F138 is dropped. Rejected: keep it as a second name. Undo: one `package.json` line. Plan D13.
4. **[important: user-visible] `eval --json <file>` becomes `eval --json-out <file>`.** Default: rename, because bare `--json` means "one JSON value on stdout" in every tool. Rejected: keep the old flag as the one exception. Undo: rename back in `eval-args.ts`. Plan D13.
5. **[minor] `testmail` stays in the server.** Default: keep all seven `testmail:*` commands and the module as they are; risk `outside`. The move to `tools/testmail` (`docs/product/stage-2/06-architecture-review.md` § 3.17) is a separate ticket; the coordinator may file it. Rejected: move it in this ticket (module code, not a CLI shape change).
6. **[minor] `fake-tg` keeps its own exit site.** Default: `tools/fake-telegram/src/cli-run.ts` is the second file the lint rule allows, because a tool never imports `apps/`. The ticket's acceptance names only `platform/cli.ts`; this is a narrow reading of "a script". Rejected: a new shared package (a `bun.lock` change for 30 lines).
7. **[minor] No new dev-database guard.** Default: the existing refusals stay (`e2e:seed`, `db:worktree`); no shared "not a dev DB" check. Rejected: a host or name rule (job, e2e and sim databases share no signal). Plan D9.
8. **[minor] Positional operands stay where callers use them.** Default: `db:worktree <name>`, `release:prepare <x.y.z>`, `fake-tg send <text>` and `wait <regex>` keep their positional; all else is flags. Rejected: flags only (breaks `scripts/limen-prepare.sh`, which every job runs).
