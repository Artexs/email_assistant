# F103 · open defaults for the owner

Small questions: the stages do not change with the answer. The build uses the default until the owner says otherwise. Each is a decision in [plan.md](plan.md).

| #   | Question                                                                                                                                                                | Default (used)                                                                                                                                                                                                                                             | Why                                                                                                                                                                         | Decision              |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| Q1  | Should log field names have kinds (UUID, number, code) that the writer and the types check?                                                                             | Yes                                                                                                                                                                                                                                                        | A number field cannot carry text and an id field cannot carry a code-shaped secret; the conversion adds about 60 counter names, and with kinds they need no privacy review. | D1                    |
| Q2  | Are CLI script outputs logs?                                                                                                                                            | No. Scripts print through `createCliOutput` (readable text in the terminal); only module code logs events.                                                                                                                                                 | A script's output is the answer to the operator (rule lists, usage, a mail server's reply). As events the CLIs lose their content; as log lines it would be a leak.         | D3, D4                |
| Q3  | Which Docker log driver per service?                                                                                                                                    | Only `server` writes `json-file` (the store reads only those files); `db`, `greenmail`, the new `cli` service and the store write `local`. One-off commands run in `cli` (`$C run --rm cli …`). This changes ADR 0024 point 4 ("every service json-file"). | Postgres error lines can hold row values (`DETAIL: Key (…)=(…)`), and CLI output holds what the operator asked for; vlagent cannot filter by container (V5).                | D12, D13              |
| Q4  | Does the store UI need a password on top of the tailnet?                                                                                                                | No password; tailnet only on its own HTTPS port 9443 (`tailscale serve`).                                                                                                                                                                                  | ADR 0017: the tailnet holds only the owner's devices. A password would be a new secret to keep.                                                                             | D15                   |
| Q5  | Do the E8 Should items (`POST /api/client-errors`, Dependabot, secret scanning, Trivy, threat model, key rotation runbook, load test, IMAP IDLE) belong to this ticket? | No. E8a is "logger, context, conversion, store" (E8 decision 12). They need a ticket of their own or a place in E8b (F114); the coordinator decides.                                                                                                       | Keeps this ticket at its decided boundary.                                                                                                                                  | ticket § Out of scope |
| Q6  | Should the store accept writes and deletes from any tailnet device?                                                                                                     | Yes, as today's panel model: the store listens on `127.0.0.1` and Serve exposes it to the tailnet only. VictoriaLogs has no read-only mode on the same port.                                                                                               | Same trust boundary as the operator console; no secret.                                                                                                                     | D14, D15              |
