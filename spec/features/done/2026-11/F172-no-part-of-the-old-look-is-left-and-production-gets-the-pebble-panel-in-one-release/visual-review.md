**Run after the fixes (stage 04):** 2026-11-25 13:45–13:49 (+01:00), `bun run web:build:dev`, then `bun run ui:sheet` with `UI_SHEET_ROUTES` set to the 33 routes with a session (every route but the public ones; the colour scheme, the tab bar and the soft hover reach all of them) into the same folder. Result: 34 tests passed, 356 pictures (the 352 of the table and the four `no-organization-*` pictures), 0 sideways-overflow marks. Fixed rows read again in the new pictures: the ring at 0 (review, onboarding), the dark checkbox (mailboxes-reply-style desktop dark), the empty-state card (activity-empty desktop), the Categories rows (settings-reply-style phone Polish), the Polish tab (approvals phone), the off states and the lead (delegates-off phone, review-off phone dark, approvals-off desktop), "Up next" (approval-detail desktop), the rule columns and the placeholder (rules-urgency desktop dark, rules-newsletters phone Polish), the activity row (activity phone), the report (report phone and desktop), the head action (mailboxes-empty phone), the timezone card (settings phone), the link chips (settings-reply-style desktop Polish) and the newsletter rows (rules-newsletters phone Polish). Not read in a picture: the activity list width, the Stats ring, the delete-card edge (no sheet state shows it), the soft hover, the hash scroll and the focus scroll; unit tests or the e2e suite cover them.

**How the pictures were read.** Each mockup shot sat next to the sheet picture of the same route, size and scheme, in English. A phone picture of the sheet is a full page at 360 px; it was cut to the first screen for the mockup table. Every other route was read in phone light, desktop dark and phone light Polish. A picture cannot show a second `h1` or an emoji in a hidden text; the leftover guards (emoji in panel texts) and the page head contract (one `h1` from the shell) cover those, and no picture showed either.

**Verdicts.** Mockup table: `match`, `accepted` (with the decision id), `fix` (difference, file or pattern, size), `proposal` (follow-up ticket). Route table: `ok`, `fix`, `proposal`. A fix that several rows share is named once per row with the same file; stage 04 changes it once.
